# Публикация Alifbo

Тексты, иконка, баннер и скриншоты лежат в [fastlane/metadata/android](../fastlane/metadata/android)
на трёх языках (uz, ru-RU, en-US). Их же автоматически берёт F-Droid.

Ссылка на политику конфиденциальности: https://uktamov-sh.github.io/alifbo/privacy.html

## Google Play

Нужен аккаунт разработчика (разовый взнос $25). Для нового личного аккаунта Google требует
закрытое тестирование: не меньше 12 тестировщиков, 14 дней подряд, прежде чем откроется продакшн.

1. Создайте приложение: название `Alifbo: yangi özbek alifbosi`, приложение (не игра), бесплатное.
2. Загрузите `alifbo-0.1.0.aab` из выпуска на GitHub во «Внутреннее тестирование», затем в «Закрытое».
3. Подпись: при первой загрузке Google предложит **Play App Signing**. Соглашайтесь: ключ из
   `C:\Users\HP\.alifbo-signing` станет ключом загрузки, а Google будет подписывать APK своим.
4. Страница в магазине: тексты из `fastlane/metadata/android/<язык>/`, иконка `images/icon.png`,
   баннер `images/featureGraphic.png`, скриншоты `images/phoneScreenshots/`.
5. Категория: «Инструменты» (Tools). Контактная почта — ваша (обязательна, видна всем).

### Готовые ответы на анкеты

| Раздел | Ответ |
|---|---|
| Доступ к приложению | Всё доступно без входа в аккаунт |
| Реклама | Нет |
| Безопасность данных: собирает ли приложение данные | **Нет** |
| Передаёт ли данные третьим лицам | **Нет** |
| Шифрование при передаче | Не применимо: приложение ничего не передаёт |
| Удаление данных по запросу | Не применимо: данные не собираются |
| Целевая аудитория | 13+ (можно и все возрасты: данные не собираются) |
| Возрастной рейтинг (анкета IARC) | На все вопросы о насилии, азартных играх и т.п. — «Нет»; общения между пользователями нет |
| Новостное приложение | Нет |
| Приложение для госорганов | Нет |
| Финансовые функции | Нет |
| Медицинское приложение | Нет |

Android сам покажет при включении стандартное предупреждение о сторонней клавиатуре. Google может
попросить объяснить, зачем клавиатуре доступ к тексту: «Это метод ввода (IME). Текст обрабатывается
только на устройстве, у приложения нет разрешения на интернет».

## F-Droid

F-Droid собирает приложение сам из исходного кода и подписывает своим ключом.

1. Зарегистрируйтесь на gitlab.com.
2. Сделайте форк https://gitlab.com/fdroid/fdroiddata.
3. Добавьте файл [fdroid/uz.alifbo.keyboard.yml](fdroid/uz.alifbo.keyboard.yml) в папку `metadata/`
   вашего форка и откройте merge request. Проверка обычно занимает от нескольких дней до нескольких недель.

## Ключ подписи

Ключ лежит в `C:\Users\HP\.alifbo-signing\` (файл `alifbo-release.jks` и пароль в
`keystore.properties`) и в репозиторий не попадает. **Сделайте резервную копию этой папки** на флешку
или в менеджер паролей: без ключа нельзя выпустить обновление APK для тех, кто поставил его с GitHub.
