Qöllanma

Örnatiş va foydalaniş — 2 daqiqa.

⬇ PDF qöllanma (özbekça va rusça)

Android telefon

Örnatiş

  1. Yuklab oliş sahifasidan alifbo-0.1.1.apk faylini yuklab oling va oçing.
  2. Telefon «nomaʼlum manbadan örnatiş»ga ruxsat sörasa — ruxsat bering.
  3. Alifbo ilovasini oçing va ekrandagi 3 qadamni bajaring:
    • «Sozlamalarni oçiş» → Alifbo klaviaturasini yoqing. Android ogohlantiriş körsatadi — bu odatiy, ilovada internet yöq.
    • «Klaviaturani tanlaş» → Alifbo klaviaturasi.
    • Pastdagi maydonda sinab köring.

Foydalaniş

  • Ş, Ç, Ö, Ğ va ʼ asosiy qatorlarda: oddiy bosing.
  • 🌐 — özbekça ↔ rusça. Uzoq bosilsa — boşqa klaviaturani tanlaş.
  • eski→yangi (tepadagi tugma) — maydondagi eski lotin yoki kirill matnni yangi alifboga öğiradi.
  • Tepada söz tavsiyalari çiqadi — kerakli sözni bosing.
  • 😊 — emoji, ?123 — raqamlar va belgilar.
  • Yuqori qatordagi harfni uzoq bosing — raqam çiqadi. ⇧ ikki marta — katta harflar.
  • Tebraniş, ovoz, tugmalar balandligi — Alifbo ilovasidagi «Sozlamalar»da.

Windows kompyuter

Örnatiş

  1. Yuklab oliş sahifasidan alifbo-setup-0.1.1.exe ni yuklab oling va işga tuşiring.
  2. Windows «nomaʼlum noşir» deb ogohlantirsa: Batafsil → Baribir işga tuşiriş.
  3. «Keyingi» → «Örnatiş». Tayyor.

Foydalaniş

  • Win + Probel — Özbek (yangi alifbo) tartibini tanlang.
  • Yangi harflar: [ ğ, ] ö, \ ç, ; ş, ' ʼ. Katta harf — Shift bilan.
  • Eski belgilar [ ] \ ; ' — öng Alt (AltGr) bilan.
  • Eski matnni öğiriş: matnni belgilang va Ctrl + Shift + Y ni bosing.
  • Öçiriş: Windows sozlamalari → Ilovalar → Alifbo → Öçiriş.

Инструкция

Установка и использование — 2 минуты.

⬇ Инструкция в PDF (узбекский и русский)

Телефон Android

Установка

  1. На странице загрузки скачайте alifbo-0.1.1.apk и откройте его.
  2. Если телефон попросит разрешить установку из неизвестного источника — разрешите.
  3. Откройте приложение Alifbo и выполните 3 шага на экране:
    • «Открыть настройки» → включите Клавиатура Alifbo. Android покажет предупреждение — это стандартно, интернета у приложения нет.
    • «Выбрать клавиатуру» → Клавиатура Alifbo.
    • Попробуйте в поле внизу.

Как пользоваться

  • Ş, Ç, Ö, Ğ и ʼ на основных рядах: просто нажимайте.
  • 🌐 — узбекский ↔ русский. Долгое нажатие — выбор другой клавиатуры.
  • eski→yangi (кнопка сверху) — переписывает текст поля со старой латиницы или кириллицы на новый алфавит.
  • Сверху появляются подсказки слов — нажмите нужное.
  • 😊 — эмодзи, ?123 — цифры и символы.
  • Долгое нажатие на букву верхнего ряда — цифра. ⇧ два раза — все заглавные.
  • Вибрация, звук, высота клавиш — в «Настройках» приложения Alifbo.

Компьютер Windows

Установка

  1. На странице загрузки скачайте alifbo-setup-0.1.1.exe и запустите.
  2. Если Windows предупредит о неизвестном издателе: Подробнее → Выполнить в любом случае.
  3. «Далее» → «Установить». Готово.

Как пользоваться

  • Win + Пробел — выберите раскладку Özbek (yangi alifbo).
  • Новые буквы: [ ğ, ] ö, \ ç, ; ş, ' ʼ. Заглавные — с Shift.
  • Прежние символы [ ] \ ; ' — с правым Alt (AltGr).
  • Переписать старый текст: выделите его и нажмите Ctrl + Shift + Y.
  • Удаление: Параметры Windows → Приложения → Alifbo → Удалить.
