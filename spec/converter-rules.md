# Правила конвертера

Конвертер переписывает текст на новый узбекский алфавит (закон O‘RQ-1184 от 21.10.2026).
На вход принимается старая латиница, кириллица или их смесь.

Эталонные примеры лежат в [cases.txt](cases.txt). Любая реализация (Kotlin для Android,
C# для Windows, JavaScript для прототипа) обязана проходить их все.

## Что не трогается

- Адреса сайтов и почты: всё, что содержит `://`, начинается с `www.` или похоже на `имя@домен.зона`.
- Sh и ch в тексте, где уже есть буквы Ş или Ç. Такой текст написан новым алфавитом,
  и `sh` в нём — две буквы (`Toşkent va Ishoq` не меняется).
- Отдельное слово `Ishoq` без Ş и Ç определить нельзя: оно будет прочитано как старая латиница
  и станет `Işoq`. Это ограничение, а не ошибка.

Исключение — кнопка «eski→yangi» на клавиатуре (режим `assumeOldLatin`). Её нажимают именно
для старого текста, поэтому sh/ch переписываются всегда, даже если в поле уже есть Ş или Ç:
`Şahar, choy` → `Şahar, çoy`. Цена решения: слово нового алфавита с настоящими s+h
(`Ishoq`) станет `Işoq`. Решение принято 22.10.2026.
- Сочетание `ng` остаётся двумя буквами.

Текст обрабатывается по словам. Слово с кириллицей переписывается по кириллическим правилам,
слово без кириллицы — по правилам старой латиницы. Поэтому `Исҳоқ` даёт `Ishoq`, а не `Işoq`.

## Старая латиница → новая

| Было | Стало | Примечание |
|---|---|---|
| Oʻ oʻ | Ö ö | апостроф любой: `ʻ ‘ ’ ' ʼ ` ´` |
| Gʻ gʻ | Ğ ğ | так же |
| Sh sh | Ş ş | |
| Ch ch | Ç ç | |
| s'h, c'h | sh, ch | апостроф означал, что буквы читаются раздельно (`Is'hoq` → `Ishoq`) |
| апостроф между буквами | ʼ (U+02BC) | тутук белгиси (`ma'no` → `maʼno`) |

Апостроф после o/g считается частью буквы, только если за ним идёт буква или ещё один апостроф
(`mo''jiza` → `möʼjiza`), либо это знак `ʻ`/`‘`.
Иначе это кавычка: `'radio'` остаётся как есть.

## Кириллица → новая латиница

Буквы: а a, б b, в v, г g, ғ ğ, д d, ж j, з z, и i, й y, к k, қ q, л l, м m, н n, о o, ў ö,
п p, р r, с s, т t, у u, ф f, х x, ҳ h, ч ç, ш ş, щ ş, ъ ʼ, ь — (выпадает), ы i, э e,
ё yo, ю yu, я ya.

- **е** → `ye` в начале слова, после гласной, после ъ и ь; иначе `e` (`ер` → `yer`, `поезд` → `poyezd`, `кеча` → `keça`).
- **ц** → `ts` после гласной; иначе `s` (`цирк` → `sirk`, `милиция` → `militsiya`, `концерт` → `konsert`).

Регистр: если в слове две и больше заглавных букв и нет строчных, слово целиком пишется заглавными
(`ЎЗБЕКИСТОН` → `ÖZBEKISTON`). Иначе заглавной становится только первая буква замены (`Ёз` → `Yoz`).

Заглавные буквы всегда получаются без учёта языка системы. Иначе на телефоне с турецкой локалью
`i` превратилась бы в `İ`.

## Чего конвертер пока не умеет

- Отличать английские слова: `shop` станет `şop`. Это исправит словарь исключений на этапе словаря.
- Обратное направление (новый алфавит → старый или кириллица).
