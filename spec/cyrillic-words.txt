# Словарь для перевода на кириллицу: «основа новой латиницей → основа кириллицей».
# Нужен только для слов, которые правила (spec/converter-rules.md) пишут неверно:
# в основном русские заимствования с ц, ь, ъ, э.
# Основа срабатывает в начале слова, если за ней ничего нет, идёт согласная или «i»
# (sirk, sirkda, sirki → цирк…, но sirka → сирка).
# Конечный ь пишется только в конце слова: sentyabr → сентябрь, sentyabrda → сентябрда.
# После правки запустить: node tools/gen-cyrillic-words.js
